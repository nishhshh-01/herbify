# Herbify 🌿

Herbify is a modern herbal wellness and plant discovery platform designed to help users explore medicinal herbs, understand their benefits, and discover natural wellness alternatives through an intuitive digital experience.

---

# ✨ Features

* 🌱 Explore medicinal herbs and plants
* 🔍 Search and filter herbal remedies
* 📖 Detailed herb information pages
* 💊 Health benefits and traditional uses
* 📱 Responsive modern UI
* ⚡ Fast Next.js performance
* 🎨 Clean and nature-inspired design system
* 📊 Scalable frontend architecture

---

# 🛠 Tech Stack

* React Native
* Expo
* TypeScript
* React Navigation
* NativeWind / Tailwind CSS
* Firebase / Supabase (optional backend)

---

# 🌿 Core Idea

Herbify aims to make herbal knowledge more accessible and engaging for modern users by combining:

* educational herbal content
* modern product-style UI/UX
* intuitive browsing experience
* wellness-focused design

The platform bridges traditional herbal awareness with modern web experiences.

# ⚡ Local Setup

Clone the repository:

```bash
git clone https://github.com/nishhshh-01/herbify
```

Install dependencies:

```bash
npm install
```

Run the Expo development server:

```bash
npx expo start
```
